# Що треба зробити — Wall Protocol

Нижче не «список на місяці», а короткий шлях від поточної вертикальної версії до сильнішої портфолійної збірки.

## P0 — перевірити перед наступною розробкою

- [ ] Відкрити `Wall Protocol.yyp` саме у GameMaker 2026.x.
- [ ] Запустити Project Health.
- [ ] Зробити compile/run smoke-test на Windows.
- [ ] Пройти всі 8 хвиль хоча б двічі: один раз із різними вежами, один раз із x2 speed.
- [ ] Якщо GameMaker автоматично перепише `.yy`, переглянути diff перед commit.

## P1 — найбільший приріст портфолійної якості

- [ ] Замінити процедурні силуети на невеликий узгоджений набір власних спрайтів: 3 вежі, 4 вороги, база, портал.
- [ ] Додати 5–8 коротких SFX: постріл, rune blast, frost hit, смерть, прорив, build/upgrade, UI click.
- [ ] Додати 1 loop атмосферної музики з регулятором гучності та mute.
- [ ] Додати прості death particles / hit flash / невеликий screen shake на прориві або босі.
- [ ] Провести баланс 8 хвиль так, щоб перше проходження тривало приблизно 10–15 хвилин.

## P1 — UX

- [ ] Tooltip із точними damage/range/fire rate перед купівлею.
- [ ] Показувати склад наступної хвилі.
- [ ] Додати гарячі клавіші будівництва 1/2/3 після вибору майданчика; поточні 1/2 зайняті speed, тому спочатку перепризначити speed.
- [ ] Виділяти ворога, якого зараз таргетить вибрана вежа.
- [ ] Додати confirmation лише для дорогого продажу/перезапуску, не для кожної дрібної дії.

## P2 — технічне упорядкування після стабілізації

- [ ] Винести числовий баланс у `scr_balance` або окремі structs.
- [ ] Винести UI drawing helpers, щоб скоротити `Draw_0.gml`.
- [ ] Додати debug overlay (FPS, enemies, wave state), який вимикається в release.
- [ ] Додати settings save: music/SFX volume, language, fullscreen.
- [ ] Додати автоматичний мінімальний тест старту гри після значних змін, якщо обраний workflow це дозволить.

## Не потрібно робити до першого портфолійного релізу

- процедурно згенеровані карти;
- десятки веж;
- skill tree/meta progression;
- multiplayer;
- складний inventory;
- аккаунти/сервер;
- 30+ хвиль;
- сюжетна кампанія з катсценами.

Для портфоліо сильніше працює 10–15 хвилин відполірованої гри, ніж велика кількість недоведеної системи.

Переробити гру і покращити її. Має бути розділенно на багато об'єктів а не на один ігровий обєкт.Кімнати: головне меню, текстова кімната і кімната гри. Обєкти мають бути роставлені в кімнатах(меню, ігрова кімната) щоб я міг модифікувати гру. Автоматичне роставлення остав на випадок якщо щось не вистачає і помилок. Добав ігрову іконку гри замість стандартної GameMaker.  Добавити графіку і звуки. Дві мови(англійську і українську). Початкове вікно з назвою компанії розробника і при першому запуску меню вибору мови. Головне меню, меню паузи і меню опцій. Завантаження і зьередення гри. 
В цілому відполірувати, виправити помилки і покращити гру, щоб я міг її використовувати для свого портфоліо. Її має не стидно показати людям.
